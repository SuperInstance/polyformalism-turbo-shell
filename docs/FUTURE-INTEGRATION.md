# Future Integration: polyformalism-turbo-shell

## Current State
A neuroscience-informed MCP server that turns any AI agent into a creative cognition engine. Implements the DMN-ECN switching model from brain research (Chen et al., 2025, N=2,433): GENERATE (DMN, wild ideas) → ROUTE (Salience Network, detect worthy ideas) → EVALUATE (ECN, critical analysis) → SYNTHESIZE (Brain Valuation System, novelty × adequacy scoring).

## Integration Opportunities

### With room creative problem-solving
When a room encounters a novel situation (no matching skill, no cached strategy), the turbo-shell kicks in: GENERATE wild responses (DMN mode), ROUTE to the most promising, EVALUATE against constraints, SYNTHESIZE the best response. This IS the room's creative cognition — the same mechanism the human brain uses, operationalized for agents.

### With evolution-ternary
The turbo-shell's GENERATE phase IS mutation (novel strategies), ROUTE IS selection (which to evaluate), EVALUATE IS fitness testing, SYNTHESIZE IS the final fitness score (novelty × adequacy). The turbo-shell IS creative evolution, informed by neuroscience.

### With construct-core skill creation
When construct-core needs a new skill (no existing skill matches the query), the turbo-shell generates candidate skills: GENERATE possible implementations, ROUTE to the most promising, EVALUATE against constraints (hardware tier, no_std compatibility), SYNTHESIZE the best skill spec. Skill creation via creative cognition.

## Dormant Ideas Now Unlockable
The turbo-shell was an MCP tool for human-assisted creativity. Now rooms need autonomous creativity — generating novel responses to novel situations. The neuroscience model applies perfectly to agent cognition.

## Potential in Mature Systems
Every room has the turbo-shell embedded as its creative cognition engine. Routine situations use cached strategies (lever-runner). Novel situations trigger creative cognition (turbo-shell). The room is both efficient (cached) and creative (generative), exactly like the human brain.
